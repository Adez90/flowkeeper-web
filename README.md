# flowkeeper-web

FlowKeeper's browser client — React + Vite + TypeScript, consuming `flowkeeper-api`
through a client generated from its OpenAPI spec. Not scaffolded yet — the backend
comes first. See the [FlowKeeper Blueprint](https://claude.ai/code/artifact/4121aef7-c600-4f2d-bf55-fb27e6fba16f)
for the full architecture.
